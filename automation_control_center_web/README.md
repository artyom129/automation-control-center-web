# Automation Control Center Web

A clean Flask web dashboard for data automation.

## Features

- Clean website interface, no Streamlit UI
- Russian / English language switch
- CSV cleaning and email validation
- API data sync
- Website scraper
- SQLite run history
- CSV and Excel downloads

## Run

```bash
python -m pip install -r requirements.txt
python app.py
```

Then open:

```text
http://127.0.0.1:5000
```
