# Automation Control Center (application folder)

This folder holds the Flask application. Setup, usage, configuration, and the list of fixes are in the [main README](../README.md), also available in [Russian](../README.ru.md) and [Kazakh](../README.kk.md).

```bash
pip install -r requirements.txt
python app.py        # http://127.0.0.1:5000
python -m pytest -q  # 42 tests, no network needed
```
